## 1 适用范围与文档定位

本汇编适用于公司内部计算机、网络系统设备、软件资源，以及使用这些设备和资源的人员。电脑台账设备类型含台式机、笔记本、一体机、工作站。

## 3 管理要求摘要

本节仅摘要列出主文档涉及的制度要求，不替代公司现行制度；要求原文以现行制度为准，源文件见 SOP-DESK-2026-002。

### 3.1 使用与保管

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 设备保管 | 使用人应遵守相关规定，并对所分配设备、软件与资源负直接保管与使用管理责任 | 使用人 |
| 硬件变更 | 不得私自拆卸公司计算机及相关外设，不得以任何形式更换硬件配置 | 禁止；变更须联系管理部 |
| 下班关机 | 无特殊业务需求时，办公计算机下班必须关机 | 使用人 |
| 笔记本专用 | 个人笔记本电脑仅限本人使用，部门内部禁止私自调换、以旧换新 | 使用人与部门 |

### 3.2 网络、系统与软件

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 固定 IP | 客户端设备默认自动获取 IP 地址；固定 IP 需申请，由主管部门登记并保留 | 使用人申请，主管部门登记 |
| 域与安全软件 | 办公和公用计算机由主管部门统一安装安全管理、防病毒和补丁更新软件，并加入域使用 | 严禁私自改动、删除或破坏 |
| 操作系统 | 办公计算机操作系统由主管部门负责初始化安装和重新安装 | 未经主管部门同意不得擅自安装或重新安装 |
| 标准软件 | 终端须安装公司发布的标准软件 | 使用人 |

### 3.3 数据存放与备份

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 非系统分区 | 公司业务相关数据必须存放在非系统分区 | 使用人 |
| 定期备份 | 业务经营数据定期备份，并保留访问、审批和操作记录 | 数据负责人 / IT |
| 备份与恢复流程 | 备份计划、数据恢复、备份介质报废按对应表单及审批流程执行 | 系统所有者 / IT |

### 3.4 维修

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 故障报修 | 笔记本故障应及时通知行政，并由使用者亲自交回公司 | 使用者 |
| 维修安排 | 由行政安排人员进行维修 | 行政 |

### 3.5 归还与离职

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 离职归还 | 调离本单位前须归还笔记本电脑，否则不予办理离职手续 | 使用人 |
| 归还检查 | 归还时到行政处检查，无故障后由鉴定人员确认，并在归还单签字 | 使用人 / 行政 / 鉴定人员 |

### 3.6 丢失与赔偿

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 人为损坏 | 按送修检测报告由使用者全额赔偿 | 使用者 |
| 丢失赔付 | 未满半年赔付 100%；满半年及以上按使用年限依次按 80% / 60% / 40% / 30% 赔付，由财务从工资扣除 | 使用人 / 财务 |
