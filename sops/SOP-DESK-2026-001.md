# 员工电脑全生命周期管理程序

## 审批信息

| 编制人 | 审核人 | 批准人 | 生效日期 |
| --- | --- | --- | --- |
| 段天俊 |  |  |  |

> 本文档为员工电脑全生命周期主流程，定义电脑从配给交付、使用维护、调岗、离职收回到报废处置的总框架和阶段入口。各阶段具体执行以对应细案或现行制度为准；配给交付直接按 SOP-DESK-2026-003《新员工电脑配给验收清单》执行，本文档不重复配置细节。支撑资料位置见 SOP-DESK-2026-002《员工电脑生命周期支撑资料目录》。

## 1 生命周期总览

| 阶段 | 主责 | 执行入口 |
| --- | --- | --- |
| 配给交付 | IT / 使用人 | SOP-DESK-2026-003 |
| 使用维护 | IT / 使用人 | 本程序 §3 |
| 调岗 | IT / 人事 / 使用人 | 现行制度，专项细案待补充 |
| 离职收回 | IT / 行政 / 使用人 | 本程序 §5 |
| 报废处置 | IT / 财务 / 使用人 | 现行固定资产与报废制度，专项细案待补充 |

## 2 配给交付

新员工电脑配给交付按 SOP-DESK-2026-003《新员工电脑配给验收清单》执行。交付完成后登记电脑台账、软件台账、《IT设备领用登记表》及《办公设备验收单》。

### 3.5 维修与故障

电脑维修、故障处理、权限变更等按现行制度和对应申请表单执行；相关表单及源文件见 SOP-DESK-2026-002。

## 4 调岗

员工调岗时，由人事或使用人发起，IT 负责账号、权限、邮箱、共享和数据迁移等事项。电脑是否随岗继续使用或收回，按现行制度执行；专项细案形成后由对应文档承接。

## 5 离职收回

### 5.1 IT 收回操作

| 顺序 | IT 操作 | 说明 |
| --- | --- | --- |
| 1 | 数据备份 | 按备份/恢复流程备份或迁移需要保留的数据 |
| 2 | 退出域与清理 | 退出域并清理电脑配置，按现行制度执行 |
| 3 | 归还检查 | 归还检查并登记；损坏、丢失按赔偿要求处理 |

### 5.2 归还与赔偿要求摘要

本节仅摘要列出主文档涉及的制度要求，不替代公司现行制度；要求原文以现行制度为准，源文件见 SOP-DESK-2026-002。

| 事项 | 要求摘要 | 责任与禁止 |
| --- | --- | --- |
| 离职归还 | 调离本单位前须归还笔记本电脑，否则不予办理离职手续 | 使用人 |
| 归还检查 | 归还时到行政处检查，无故障后由鉴定人员确认，并在归还单签字 | 使用人 / 行政 / 鉴定人员 |
| 人为损坏 | 按送修检测报告由使用者全额赔偿 | 使用者 |
| 丢失赔付 | 未满半年赔付 100%；满半年及以上按使用年限依次按 80% / 60% / 40% / 30% 赔付，由财务从工资扣除 | 使用人 / 财务 |

## 6 报废处置

电脑达到报废条件时，由 IT 与财务按现行固定资产报废制度处理，包括数据清理、硬盘处置、报废记录、资产台账核销等。专项细案形成后由对应文档承接。
