# 员工电脑配给与收回标准作业程序书

> 本文档为草稿（Draft）。编号 `SOP-DESK-2026-001`，目标目录 03-DESK-桌面终端，关联 ISO/IEC 20000-1。文中规则依据 2026-08-20 核对的《电脑配置-智绿标准v4》《IT管理制度》《电脑信息表-260812》及现行表单整理。

## 1 适用场景

适用于公司员工电脑（台式机 / 笔记本 / 一体机 / 工作站）的全生命周期配给与收回管理，覆盖以下场景：

| 场景 | 触发 | 目标章节 |
| --- | --- | --- |
| 新员工入职配给 | HR 发出入职人员信息 | 4.2 |
| 在职员工电脑重新配给（调岗 / 换机） | HR 调岗通知或部门申请 | 4.3 |
| 员工离职且电脑不重新配给 | HR 发出离职通知 | 4.4（数据备份后收回） |
| 员工离职且电脑重新配给 | HR 发出离职通知并确定接收人 | 4.5（数据迁移后重新配给） |

## 3 职责与权限

| 角色 | 职责 | 禁止事项 |
| --- | --- | --- |
| IT（资产管理 / 服务台） | 配给执行：选型、装机、加域、网络配置、软件安装、业务权限开通；离职数据备份与迁移；收回处置；资产台账维护 | 严禁未经签具交付电脑；严禁未经确认备份完成即清除数据 |
| HR | 入职 / 离职 / 调岗信息发起与通知，明确配给或收回需求 | 严禁泄露账号密码等敏感信息 |
| 部门经理 / 直属上级 | 确认岗位配置需求；离职时指定数据接收人（继任者 / 上级）；配合催收未归还电脑 | 严禁代签领用 / 归还文件 |
| 员工本人 | 领用时签具《IT设备领用登记表》《笔记本电脑使用协议》并妥善保管；离职时按流程归还并签具 | 严禁私自转借、拆卸、改装、未经批准外带 |

依据《IT管理制度》与《笔记本电脑管理制度》：使用人对所分配设备负保管与使用管理责任；不得私自拆卸、更换硬件或安装操作系统；硬件配置或存放位置变更须联系管理部做资产变更；办公电脑下班后无特殊业务需求必须关机；笔记本专人专用，部门内部禁止私自调换、以旧换新。

## 4 操作步骤

### 4.1 场景路由

IT 收到 HR 或部门发起的人员变动信息（姓名、职位、工号、部门、入职 / 离职日期），按场景路由：

| 变动类型 | 路由 |
| --- | --- |
| 入职 | 4.2 新员工入职配给 |
| 调岗 / 换机 | 4.3 在职重新配给 |
| 离职（电脑不重新配给） | 4.4 数据备份后收回 |
| 离职（电脑重新配给） | 4.5 数据迁移后重新配给 |

### 4.2 新员工入职配给

| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | HR 向 IT 发送入职人员信息（姓名、职位、工号、部门、入职日期） | IT 收到完整入职人员信息 |
| 2 | IT 按 2.1 配给规则选定机型（优先从备机库存调配，不足时提交新购申请） | 确定配给机型与配置 |
| 3 | 装机与配置：操作系统统一安装并升级为专业版、计算机名命名、加域、网络配置并登记有线 / 无线 MAC、标准软件安装 | 装机完成，可正常登录 |
| 4 | 业务权限开通：按岗位通过《账号申请单》《权限申请单》申请 MES / U9 / PLM 等权限 | 业务系统权限就绪 |
| 5 | 交付：当面交付电脑及配件，员工签具《IT设备领用登记表》（资产编号、设备名称、品牌型号、SN 编码、领用部门、工号、领用人签字、日期、备注），登记 MAC / SN / 计算机名、固定资产编号 | 签具完成，登记信息完整 |
| 6 | 资产台账更新：登记领用人、领用日期、资产状态 | 台账与实物一致 |
| 7 | 通知 HR 配给完成 | 流程闭环 |

### 4.3 在职员工电脑重新配给（调岗 / 换机）

| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | 收到调岗通知或换机申请 | 变更需求确认 |
| 2 | 评估：按 2.1 配给规则判断新岗位是否需要更换机型 | 明确换机或沿用 |
| 3 | 数据迁移：将旧机工作文件迁移至新机 | 迁移完成且可访问 |
| 4 | 权限调整：域、软件、业务系统权限按新岗位调整（《账号申请单》《权限申请单》） | 权限与岗位匹配 |
| 5 | 旧机处置：归还入库或按资产制度报废，必要时填写《办公设备验收单》 | 旧机台账状态更新 |
| 6 | 签具登记：新机《IT设备领用登记表》签具 | 签具完成 |
| 7 | 资产台账更新 | 台账与实物一致 |

### 4.4 员工离职收回（电脑不重新配给）

| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | HR 向 IT 发送离职通知，明确该电脑不重新配给 | IT 收到收回需求 |
| 2 | 数据备份（见 4.4.1）：将工作文件备份至企业网盘，确认备份完成 | 备份完成并通过完整性校验 |
| 3 | 账号与权限处理：域账号停用、业务系统权限回收（与 SEC 域人员变动流程衔接） | 账号权限已回收 |
| 4 | 回收：员工归还电脑及配件，IT 检查设备完整性 | 设备及配件齐全 |
| 5 | 签具：按《笔记本电脑管理制度》由使用人亲自到行政 / IT 处检查，鉴定人员确认后在归还记录（《IT设备领用登记表》或《笔记本使用申请表》归还栏）签字 | 签具完成 |
| 6 | 处置：清除个人数据（重装系统或按存储介质销毁规范处理），资产台账更新为库存可用 | 数据已清除，台账已更新 |
| 7 | 通知 HR 收回完成 | 流程闭环 |

#### 4.4.1 离职数据备份细则

| 项目 | 规则 | 状态 |
| --- | --- | --- |
| 备份范围 | 桌面、文档、工作目录、邮件（Foxmail 数据）、浏览器收藏、非系统分区业务数据等 | 依据《IT管理制度》 |
| 备份目标 | 企业网盘 / 共享盘，按 `姓名-工号-离职日期` 归档 | 已确认（用户 2026-08-19 答复） |
| 完整性校验 | 备份完成后抽查文件数量与关键文件可打开性，确认完整后再回收 | 执行要求 |
| 备份流程表单 | 备份计划、备份检查记录、数据恢复申请、介质报废、备份记录表等按《数据备份计划》至《数据备份记录表》执行 | 待确认正式表单编号 |

### 4.5 员工离职数据迁移后重新配给

| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | HR 发送离职通知，并确定电脑接收人（新员工或转岗员工） | 接收人确定 |
| 2 | 数据迁移：将工作文件备份至企业网盘，授权继任者或直属上级访问 | 迁移完成，接收人可访问 |
| 3 | 权限移交：业务系统（MES / U9 / PLM）账号权限迁移或回收 | 权限移交完成 |
| 4 | 系统重置：清除个人数据、重装系统 | 数据已清除 |
| 5 | 重新配给：按 2.1 配给规则与接收人岗位装配，交付签具《IT设备领用登记表》 | 签具完成 |
| 6 | 资产台账更新 | 台账与实物一致 |

## 5 注意事项（异常处理）

| 异常ID | 现象 | 原因 | 处置 |
| --- | --- | --- | --- |
| E1 | 数据备份失败 | 存储空间不足 / 文件被占用 / 加密文件 | 检查空间、关闭占用进程后重试；仍失败上报 IT 主管，未确认备份成功前不得清除数据 |
| E2 | 离职员工未归还电脑 | 员工未配合 / 流程遗漏 | 部门经理与 HR 跟进催收；必要时按公司资产管理制度处置 |
| E3 | 设备故障 | 硬件或软件异常 | 使用人填写《电脑维修申请单》，IT 检测维修并记录处理意见与维修费用 |
| E4 | 设备损坏 / 丢失 | 人为原因 | 按《IT管理制度》《笔记本电脑管理制度》承担费用：人为损坏按送修检测报告全额赔偿；丢失按使用年限赔付（未满半年 100%、满半年 80%、满二年 60%、满三年 40%、满四年及以上 30%），由财务部从工资扣除，并联系管理部做资产变更 |
| E5 | 库存无匹配机型 | 库存不足 | 提交采购申请，或按《电脑配置-智绿标准v4》与员工协商同级机型替代，经 IT 主管确认 |
