# 安防平台人员变动信息处理标准作业程序书

## 审批信息
| 编制人 | 审核人 | 批准人 | 生效日期 |
| --- | --- | --- | --- |
| 段天俊 |  |  |  |

## 适用场景
适用于安防平台下指定门禁子系统发卡操作。

## 前置条件

### 配置参数
| 配置项 | 值 / 说明 |
| --- | --- |
| 适用门禁子系统 | 安防平台下指定门禁子系统 |
| 涉及设备型号 | 海康威视 DS-K1F600-D6E / DS-K1F600U-D6E 发卡器 |
| 设备类型选项 | 下拉选择：DS-K1F600-D6E / DS-K1F600U-D6E |
| 写卡机 IP | 发卡器分配的静态 IP 地址（10.0.49.36） |
| 其余参数 | 保持系统默认值 |

### 硬件与网络就绪
- 发卡器已通过 USB 数据线连接至电脑，并已安装对应 USB 驱动（系统识别为 HID 设备）；或发卡器与电脑网络互通。
- 操作电脑与安防平台服务器网络互通。

### 系统环境就绪
（1）系统证书安装：浏览器提示"为了保证您的账号及信息安全，请安装根证书！如已安装，请忽略！"。首次登陆则安装。
（2）浏览器插件安装：在【人员发卡】界面提示"调用控件失败，请下载安装浏览器控件"时执行。关闭浏览器后安装。

## 职责与权限
| 角色 | 职责 | 禁止事项 |
| --- | --- | --- |
| 系统管理员 | 负责执行综合安防管理平台人员信息更新、卡片移交和发卡器配置及异常处理 | 严禁非授权人员操作发卡界面或修改发卡器参数 |

## 操作步骤

### 5.1 人员信息接收
系统管理员收到管理部或相关方提交的人员变动信息清单（工号、姓名、身份证号、白底人脸电子证件照及人员变动类型），按变动类型至后续对应场景：

| 变动类型 | 目标章节 | 时效要求 |
| --- | --- | --- |
| 入职 | 5.2 入职发卡流程 | 如上午接收到入职信息清单且无特殊情况，须于当日 12:00 前完成卡片移交 |
| 调岗 | 5.3 调岗流程 | 收到后及时处理 |
| 离职 | 5.4 离职流程 | 收到后及时处理 |

### 5.2 入职发卡流程

#### 5.2.1 登录平台
| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | 输入用户名及密码，点击【登录】 | 进入平台首页 |
| 2 | 登录成功后，在右上角下拉菜单中点击【系统管理】 | 打开系统管理 |
| 3 | 在左侧菜单栏或系统管理主界面中，找到并点击【人员发卡】模块 | 打开人员发卡模块 |

#### 5.2.2 新建档案
| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | 进入人员管理模块，新建人员档案 | 打开新建人员档案界面 |
| 2 | 录入工号、姓名、身份证号 | — |
| 3 | 照片规格要求对齐平台以及人事要求 | — |

#### 5.2.3 人员开卡
| 序号 | 动作 | 预期结果 / 校验点 |
| --- | --- | --- |
| 1 | 点击相应人员的【开卡】按钮 | 系统弹出"发卡配置/操作"对话框 |
| 2 | 放卡于发卡器感应区域 | — |
| 3 | 观察平台界面上的"卡号"输入框，待发卡器蜂鸣一声、卡号自动填入后保存 | 系统提示"开卡成功"，该人员持卡数更新 |

#### 5.2.4 移交卡片
安防侧完成写卡操作后，将已开卡的 IC 卡移交管理部。

### 5.3 调岗流程
员工发生调动时，系统管理员需在安防平台后台将该人员调整至新的组织架构节点。人员挂接到对应组织后门禁权限自动生效。

### 5.4 离职流程
员工离职时，由系统管理员在安防平台中删除其人脸特征和门禁卡信息后调整其组织架构至【离职人员】。

> 注意：离职流程不涉及平台侧的卡片物理重置或卡号变更操作。

## 注意事项（异常处理）
| 异常ID | 现象 | 原因 | 处置 |
| --- | --- | --- | --- |
| E1 | 卡号无法读取 | 1. 发卡器参数 IP 不正确 | 1. CMD Ping 发卡器 IP 检查连通性 |
| | | 2. 卡片放置位置偏移 | 2. 旋转卡片 180 度重新放置 |
| | | 3. 驱动未装 | 3. 重装 USB 驱动程序 |
