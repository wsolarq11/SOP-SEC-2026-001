# 员工电脑配给与收回 · 相关表单明细

> 本文件是 SOP-DESK-2026-001《员工电脑配给与收回资料汇编》的支撑资料，登记相关表单的名称、编号、字段与签核要求。对应源文件路径见 SOP-DESK-2026-003《源文件清单》。

## 相关表单

| 表单 | 原表单字段 / 编号 |
| --- | --- |
| 《IT设备领用登记表》 | 资产编号、设备名称、品牌型号、SN 编码、领用部门、工号、领用人签字、日期、备注 |
| 《办公设备验收单》 | 编号 CHA-EM4-R-010，版本 A0；IT 工程师主导本表单验收，对设备电源、配件、系统、运行确认 |

| 《账号申请单》 | CHA-EM4-R-033；申请日期、部门、工号、姓名、英文名、邮箱、所属邮箱组、相关说明；签核流程：主管签核、经理签核、IT 主管、IT 执行人 |
| 《文件共享申请单》 | CHA-EM4-R-034；部门、工号、姓名、是否涉及其他部门、文件夹路径、权限类别：只读、修改、删除、申请原因、备注；签核流程：主管、经理、总经理、各部会签、IT 执行人 |
| 《ERP申请单》 | CHA-EM4-R-035 |
| 《共享文件恢复申请单》 | CHA-EM4-R-036 |

| 《邮件外发申请单》 | CHA-EM4-R-038 |
| 《USB存储权限申请单》 | 签核流程：经理、总经理、IT 主管、IT 执行人 |
