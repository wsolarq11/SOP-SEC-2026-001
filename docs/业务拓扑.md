## 4 可执行命令拓扑（统一入口 `kb.py`）

`tools/kb.py` 是唯一命令入口：`check / test / publish / ship / line / fact / token-bootstrap / backup / auth / cleanup / registry-render / manifest / build`。依赖是干净分层：

```text
registry.json
   -> registry_lib / check_docs / registry_render / registry_manifest
   -> kb.py
   -> publish.sh / fact_ops / token_bootstrap / ship.sh
   -> sop_to_docx_stdlib -> lark 上传 -> publish_log
   -> line_report -> CI / git hooks / backup_commit
```

一处入口，无第二套清单；`tools/publish_tokens.py` 是 `.publish-tokens` 唯一读写端，`tools/lib.sh` 共享 shell 路径样板。
